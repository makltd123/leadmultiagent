# LeadMultiAgent — мониторинг B2B-лидов в Telegram

[English](README.md) | **Русский**

Автономная система, которая читает групповые чаты Telegram через userbot, находит сообщения, где люди ищут продукт или услугу вроде вашей, собирает сведения о лиде и присылает **вам** уведомление с черновиком ответа. Сама она никому не пишет: черновик приходит только вам, и отвечать или нет — решаете вы.

## Как это работает

```
Чаты Telegram ──► userbot (Pyrogram) ──► фильтр по словам ──► Classifier ──► Enricher ──► Writer ──► бот уведомлений ──► вы
                                                               score ≥ 0.7
```

| Агент | Модель | Что делает |
|---|---|---|
| Strategist | Groq `llama-3.1-8b-instant` | Превращает описание продукта (`/start`) в портрет клиента, ключевые слова, сигналы намерения и анти-сигналы |
| Classifier | Groq `llama-3.1-8b-instant` | Решает, лид ли сообщение; score 0–1, от 0.7 — явный лид |
| Enricher | NVIDIA NIM `llama-3.3-70b-instruct` | Кратко описывает, кто автор сообщения |
| Writer | NVIDIA NIM `llama-3.3-70b-instruct` | Пишет черновик ответа |
| Scout | Groq (категоризация) | Ищет подходящие чаты и вступает в них — по понедельникам в 03:00 |
| Analyst | NVIDIA NIM `llama-3.3-70b-instruct` | Еженедельный дайджест — по воскресеньям в 10:00 |

До любого обращения к LLM сообщение проходит дешёвый фильтр: +2 за сигнал намерения, +1 за ключевое слово, −3 за анти-сигнал. Сообщения с оценкой ниже `KEYWORD_MIN_SCORE`, короче 20 символов или слишком старые пропускаются.

В уведомлении есть кнопки «В работе» / «Не актуально» (статус лида) и ссылка на сообщение.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env    # Windows: copy .env.example .env
```

Заполните `.env`:

| Переменная | Где взять |
|---|---|
| `TG_API_ID`, `TG_API_HASH` | своё приложение на [my.telegram.org](https://my.telegram.org) |
| `TG_PHONE` | номер телефона аккаунта, на котором работает userbot |
| `BOT_TOKEN` | [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | ваш числовой Telegram ID — сюда приходят уведомления |
| `GROQ_API_KEY` | [console.groq.com](https://console.groq.com) |
| `NVIDIA_API_KEY` | [build.nvidia.com](https://build.nvidia.com) |
| `MAX_CHATS` | сколько чатов Scout может добавить (по умолчанию 1000) |
| `KEYWORD_MIN_SCORE` | порог фильтра (по умолчанию 2) |

```bash
python main.py
```

При первом запуске Pyrogram попросит код входа из Telegram; сессия сохранится в `session.session`. Потом напишите своему боту `/start` и опишите продукт.

## Команды бота

- `/start` — первый запуск, описание продукта
- `/setup` — изменить продукт (заново запускает Strategist и Scout)
- `/cancel` — отменить диалог настройки продукта
- `/stats` — статистика (чаты, лиды)
- `/leads` — последние 10 лидов
- `/pause` / `/resume` — пауза мониторинга

## Список чатов (необязательно)

Если рядом лежит файл `tgstat_chats.txt` (по одному username чата в строке), Scout сначала пробует эти чаты, иначе использует только поиск Telegram. `parse_tgstat.py` собирает username'ы с tgstat.ru через Playwright (`pip install playwright && playwright install chromium`), но tgstat.ru часто блокирует автоматический доступ. Сам список в репозиторий не входит.

## Запуск на сервере

- **Linux:** `leadmonitor.service` для systemd (впишите пользователя и пути) и `check_heartbeat.sh` для cron — он перезапускает сервис, если `logs/heartbeat` старше 5 минут.
- **Windows:** `register_autostart.bat` регистрирует `autostart.bat` как задачу, которая стартует вместе с системой.

## Важно

- **`session.session` даёт полный доступ к вашему аккаунту Telegram.** Никому его не передавайте и не коммитьте — он в `.gitignore`.
- В `leads.db` и `logs/` лежат сообщения и профили реальных людей из чатов. Это персональные данные: храните их только у себя.
- Вступление в сотни чатов с одного аккаунта может упереться в лимиты Telegram (`FLOOD_WAIT`) или привести к ограничениям аккаунта. Scout делает паузу 10–20 секунд между вступлениями и выжидает `FLOOD_WAIT`, но надёжнее использовать отдельный аккаунт.
- Сообщения из архивированных чатов не приходят. Вместо архива складывайте чаты в обычную папку.
- NVIDIA NIM иногда зависает, поэтому у каждого вызова таймаут 30 секунд.
- `tgcrypto` убран из зависимостей, потому что требует C++ Build Tools; Pyrogram работает и без него, просто шифрование медленнее.
